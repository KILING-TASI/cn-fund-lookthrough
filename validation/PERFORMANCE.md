# 资源限制与可复现性能参考

普通JSON CLI先限制输入文件16 MiB；原生API结构限制为根持仓100、节点1000、每节点持仓5000。穿透深度20时保留未知，基金路径访问超过100000停止；这些限制不能相乘当成推荐负载或内存保证。共享节点会沿不同路径展开；输入持仓行数、展开叶路径数和未知条目数并不相同。

本轮Windows / Python3.12.10，16逻辑CPU。原创合成负载在新进程运行，分别测试独立叶节点flat和共享叶节点shared。不包括输入生成、JSON解析、HTML渲染或写盘时间；tracemalloc从输入构造后开始，进程生命周期峰值包括输入构造和解释器。二者分别记录，不能互相替代。本表只是这台机器的一次参考，不证明O(n)、全市场吞吐或安全上限。

| 结构 | 展开叶路径 | analyze耗时秒 | Python跟踪峰值MiB | 进程生命周期峰值MiB |
|---|---:|---:|---:|---:|
| flat | 1000 | 0.031 | 0.57 | 21.85 |
| flat | 10000 | 0.327 | 5.36 | 41.05 |
| flat | 50000 | 1.601 | 30.98 | 128.46 |
| shared | 1000 | 0.033 | 0.58 | 21.81 |
| shared | 10000 | 0.146 | 3.95 | 30.03 |
| shared | 50000 | 0.629 | 18.95 | 64.43 |

完整参数、生成输入SHA、引擎源文件SHA及内存口径见[原始记录](performance-reference-20261010.json)。复现需在完整源码目录运行，并使用新文件：

```powershell
python tools/benchmark.py --counts 1000,10000,50000 --out local-data/performance-first.json
```

复现工具限定不超过500000请求叶路径，默认不跑数百万规模；每项超时180秒，失败不生成通过记录。不同机器和Python版本可能不同。原始Python API测试结果不证明CLI文件可容纳相同输入。

CLI默认长于10秒后在stderr提供节流阶段和已检查记录数，不猜百分比或ETA；`--progress`从开始显示，`--no-progress`关闭，stdout JSON保持。直接调用analyze可传可选progress回调，未传时原行为不变。512字符以上身份/展示文字只告警，不截断、不改公司映射或金额。

源文件摘要记录测量时本地字节身份；Git检出换行可能不同，不能仅凭换行导致的摘要差异推定计算方法变化。外部报告的490万条/104秒/2GB未作为本仓复测结果收录。
